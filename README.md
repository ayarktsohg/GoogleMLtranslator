# GoogleMLtranslator

Лёгкий Android-переводчик на Kotlin с локальным переводом через Google ML Kit.

Проект ориентирован на простую работу без постоянного подключения к интернету: языковые модели скачиваются на устройство и после установки могут использоваться офлайн.

## Возможности

- перевод текста через Google ML Kit Translation;
- работа с установленными языковыми моделями офлайн;
- выбор направления перевода;
- быстрая смена исходного и целевого языка;
- загрузка дополнительных языковых моделей;
- отображение свободного места перед установкой модели;
- защита от бесконечного ожидания загрузки языкового пакета;
- автоматический перевод при вводе;
- ручной запуск перевода кнопкой `→`;
- адаптация интерфейса к экранной клавиатуре;
- сохранение пользовательского расположения элементов интерфейса;
- режим редактирования интерфейса с перетаскиванием панелей и кнопок.

## Технологии

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
- Google ML Kit Translation
- Gradle Kotlin DSL

## Минимальная версия Android

```text
minSdk = 23
```

## Структура проекта

Основные файлы:

```text
app/src/main/java/com/example/googlemltranslator/
├── MainActivity.kt
├── LanguageCatalog.kt
├── DebugConfig.kt
└── ui/theme/
```

`MainActivity.kt` содержит основную логику интерфейса, перевода, работы с языковыми моделями и редактора компоновки.

`LanguageCatalog.kt` формирует список языков, поддерживаемых ML Kit.

## Как запустить проект

1. Клонировать репозиторий:

```bash
git clone <URL_РЕПОЗИТОРИЯ>
```

2. Открыть папку проекта в Android Studio.
3. Дождаться завершения Gradle Sync.
4. Подключить Android-устройство с включённой USB-отладкой или запустить эмулятор.
5. Запустить конфигурацию `app`.

Для первоначальной загрузки языковой модели устройству требуется доступ в интернет.

После загрузки соответствующих моделей перевод может работать офлайн.

## Сборка APK

Для тестовой debug-сборки:

```text
Build
→ Build Bundle(s) / APK(s)
→ Build APK(s)
```

Готовый файл обычно появляется здесь:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Языковые модели

Приложение использует `RemoteModelManager` из Google ML Kit.

Неустановленные модели можно скачать из интерфейса приложения. Перед установкой приложение проверяет доступное место во внутреннем хранилище.

Если загрузка модели не завершается в установленный срок, приложение дополнительно проверяет, была ли модель фактически установлена, и вместо бесконечного индикатора показывает ошибку.

## Редактор интерфейса

Кнопка `⚙` включает режим редактирования.

В этом режиме можно менять расположение:

- панели результата;
- панели управления;
- панели ввода;
- кнопок внутри панели управления;
- элементов панели ввода.

Порядок элементов сохраняется между запусками приложения.

## Конфиденциальность и секреты

В репозиторий не должны попадать:

- `local.properties`;
- API-ключи;
- пароли и токены;
- `.jks` и `.keystore`;
- данные подписи release-сборки.

Эти файлы исключены через `.gitignore`.
